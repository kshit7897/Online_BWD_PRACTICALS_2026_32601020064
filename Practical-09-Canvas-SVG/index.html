2. SVG – College Logo

SVG (Scalable Vector Graphics) draws shapes using XML tags, so it stays sharp at any zoom level.

Difference between Canvas and SVG

CanvasSVG
Raster (pixel based)Vector (shape based)
Drawn with JavaScriptWritten as XML tags
Becomes blurry on zoomStays sharp on zoom
Each shape cannot be selected laterEach shape is a DOM element
Best for games and charts with many pointsBest for logos, icons and maps
